## Comment récupérer d'autres transcriptions (méthode qui marche ici, réseau ouvert)
```bash
yt-dlp --js-runtimes "node:/opt/node22/bin/node" \
  --extractor-args "youtube:player_client=tv" \
  --skip-download --write-auto-subs --sub-langs "fr" --sub-format vtt \
  -o "%(id)s" "https://www.youtube.com/watch?v=VIDEO_ID"
```
(le client `tv` passe sans PO token, contrairement à `web`/`android`)
