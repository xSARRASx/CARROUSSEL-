Il est 21h, le voyageur ne trouve pas le code. Tu réponds, tu raccroches, et tu attends le prochain message. Ce qui est pesant, ce n'est pas le nombre d'appels : c'est de ne jamais savoir quand le suivant va tomber.

Avant de changer quoi que ce soit, prends une semaine d'observation. Chaque sollicitation : quand, par quel canal, quel logement, quel motif. Puis la colonne qui change tout : qu'est-ce qui aurait permis de la traiter sans toi ? Note aussi les interruptions que tu te provoques toi-même.

Trois lignes de ce registre, trois problèmes différents. Code introuvable : une information mal présentée. Arrivée anticipée : une règle qui manque. Fuite sous l'évier : là oui, il faut quelqu'un sur place. Les mettre dans le même panier, c'est chercher une seule solution pour trois causes.

Ensuite, trois couches.

Rendre l'information trouvable. Sors les instructions d'accès du message de vingt-cinq lignes : adresse, heure, emplacement de la boîte, photo de la bonne entrée. Montre au lieu d'expliquer.

Programmer les réponses répétitives, avec une séquence qui se rejoue à chaque réservation.

Déléguer ce qui reste. Une personne, souvent celle qui fait déjà le ménage, avec une astreinte convenue. Une ligne dédiée, avec un transfert réellement testé. Et surtout une page de règles : ce qu'elle traite seule, ce qui attend un créneau, ce qui exige une intervention immédiate.
